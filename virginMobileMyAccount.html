Virgin Mobile My Account

Sr. Mobile Developer at Bell Canada • Best Telecom Mobile Application worldwide for 2020

Project Overview & Highlights

The Virgin Mobile My Account app enables subscribers to manage their mobile account 24/7 directly from their iOS devices — pay bills, monitor data usage, manage travel passes, and change plans.

  • Engineered clean modular architecture to enable code reusability across telecom application suites.
  • Implemented APNs push notification services, deep linking, Adobe Analytics session tracking, and Dynatrace monitoring.
  • Optimized network latency and payload efficiency with Charles Proxy and Postman testing workflows.
  • Won the prestigious MobileWebAward for Best Telecom Mobile Application for 2020.
