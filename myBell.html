// Award-Winning Telecom App

MyBell App

Sr. Mobile Developer at Bell Canada • Winner of MobileWebAward for Best Telecom Application

Project Overview & Engineering Highlights

This app makes it easy to manage Bell services with quick access to a variety of features for Bell Mobility, TV, and Internet across millions of active Canadian subscribers.

  • Applied Clean Architecture principles to implement highly reusable, modular code structures, accelerating cross-app feature adoption.
  • Implemented APNs push notifications, universal deep linking, Adobe Analytics tracking, and Dynatrace APM for real-time monitoring.
  • Utilized network traffic diagnosis tools (Charles Proxy, Postman) to optimize API payload efficiency.
  • Provided technical leadership and mentorship to team developers.
  • Won the MobileWebAward for Best Telecom Mobile Application worldwide.
