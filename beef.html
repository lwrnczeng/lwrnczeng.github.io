REIBeef

Mobile Application Developer at Lallemand Inc. • Montreal, Canada

Project Summary

REIBeef is a specialized agricultural analytics iOS application designed to optimize rumen efficiency for farm managers, directly maximizing income over feed costs through automated data algorithms.

  • Built offline-first data synchronization layers utilizing Core Data, SQLite, and RESTful APIs in Swift.
  • Integrated APNs push notifications and custom charting for agricultural metrics.
  • Managed App Store distribution, TestFlight provisioning, and CI/CD pipelines.
